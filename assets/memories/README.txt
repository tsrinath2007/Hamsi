Place your photos and videos in this folder!

Examples:
- photo-01.jpg
- photo-02.jpg
- video-01.mp4
- video-02.mp4

To add them to the website, simply add an entry to the MEDIA array at the top of:
js/memories.js

Like this:
{
  type: "image",
  src: "assets/memories/photo-01.jpg",
  caption: "core memory ❤️"
},
{
  type: "video",
  src: "assets/memories/video-01.mp4",
  caption: "why were we like this 💀"
}

The website will automatically format and display them as handmade scrapbooked polaroids with taped corners!
